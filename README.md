# HoloCube GS for Mac

Light-field digital human for the Mac: plug in a DIY1 (1440×1440) or C1 (1440×2560) light-field display, then chat or interpret. Same engine as the iOS app.

**Download:** the latest notarized DMG is on the [Releases](https://github.com/sintlab/holocube-gs-mac/releases/latest) page.
Install guide, release history and the China mirror: **https://holo.sintlab.com/mac/**

Requirements: Apple Silicon · macOS 26 or later · about 1 GB.

This repository only hosts release binaries.
